A file closes when either the duration or the size limit is reached. The size limit counts logged frame data (20 bytes per frame); every file also carries a fixed ~104 KB header, as CANedge files do, so the uploaded file is about 104 KB larger. Port, baud, bucket and device ID are set in config.json (restart required).
